# Detective AI — Test Plan

Goal: measure how Detective AI behaves on **realistic** images (phone photos, chatbot images, Photoshop edits,
generative edits, messenger re-compression, screenshots), not to score well on easy AI images.

Nothing in this folder is generated by the evaluation code. Every test image is created by a person with
the named tool, registered with its provenance, and only then run through the system.

---

## 1. Ground-truth labels

Ground truth is recorded in `manifest.csv` **before** a run and never edited after looking at predictions.

| Label | Meaning | Examples |
|---|---|---|
| `REAL` | Camera capture; only ordinary in-camera processing. Transport changes (compression, resize, screenshot, format change) keep this label. | Phone photo straight from the gallery; the same photo sent through WhatsApp |
| `AI_GENERATED` | Content synthesised by a generative model from a prompt. Manual edits on top keep this label (with secondary `MANUALLY_EDITED`). | ChatGPT / Gemini text-to-image; a Gemini image retouched in Photoshop |
| `AI_EDITED` | A real photo whose pixels were partly or wholly regenerated by generative AI. | Inpainting, Photoshop **Generative Fill**, object replacement, AI upscaling, "make this photo better quality" in ChatGPT |
| `MANUALLY_EDITED` | A real photo edited only with non-generative tools. | Crop, colour/levels, clone stamp, healing brush, compositing two real photos, text overlay |
| `MIXED` | One image containing real and AI-generated elements assembled together. | Real street photo with a pasted AI-generated person |
| `INCONCLUSIVE` | Origin cannot be established. Kept in the dataset, **excluded from metrics**. | Image from the internet without provenance |

Edge-case rules:
- **Photoshop Generative Fill / Generative Expand / Firefly** count as generative AI (`AI_EDITED`). Content-Aware Fill,
  Clone Stamp, Healing Brush and Liquify are non-generative (`MANUALLY_EDITED`). Record the exact tool name; if a tool's
  nature is unclear, write that in `provenance_notes`.
- **ChatGPT/Gemini "enhance/upscale/restyle this photo"** regenerates the image → `AI_EDITED` (category A06), linked to the
  camera original.
- A generative edit applied to an image that is already `AI_GENERATED` stays `AI_GENERATED`.
- Ordinary Photoshop editing is **never** labelled as AI generation.

## 2. How predictions are scored

| Detective AI verdict | Counted as |
|---|---|
| Likely AI-generated | predicts AI involvement |
| Likely authentic photograph / No AI generation detected | predicts no AI involvement |
| Potential manipulation / editing | predicts editing, no AI claim |
| Inconclusive | abstention (reported separately, never silently dropped) |

Per image the outcome is `correct`, `incorrect` or `inconclusive`:

| Ground truth | Correct verdicts |
|---|---|
| REAL | Likely authentic, No AI detected |
| AI_GENERATED | Likely AI |
| AI_EDITED | Likely AI, Potential manipulation |
| MANUALLY_EDITED | Potential manipulation (a "Likely AI" verdict is a **false AI accusation**) |
| MIXED | Likely AI, Potential manipulation |

Metrics (all computed by `run_test_suite.py` from actual predictions):
- **AI-involvement detection** (binary): positives = AI_GENERATED, AI_EDITED, MIXED; negatives = REAL, MANUALLY_EDITED.
  Precision, recall, F1 on decided cases; recall with abstentions counted as misses; false-positive rate; coverage;
  95% Wilson confidence intervals.
- **Editing detection**: share of edited images flagged "Potential manipulation", and false-alarm rate on unedited images.
- **Confusion matrix**: ground truth × the five verdicts.
- **Breakdowns** by test category, source tool (ChatGPT / Gemini / camera) and transformation tool.
- **False-positive and false-negative lists** with the detector score, view agreement and metadata findings for each.
- **Source-weighted accuracy**: each independent source image counts once, however many derivatives it has.
- Median/maximum processing time.

## 3. Test matrix (minimum 50 images)

Columns: what to create · how · ground truth · what it tests.

| Cat. | Images | Create | How / tool to record | Ground truth | Tests |
|---|---|---|---|---|---|
| C01 | 5 | Original smartphone photos | Copy the file from the phone gallery by cable/cloud **as a file** (not via a messenger). Record phone model. Mix scenes: people, indoor, night, landscape, text/documents. | REAL | False positives on genuine photos; EXIF/timeline |
| C02 | 5 | ChatGPT text-to-image | Download the original PNG from ChatGPT. Record model/version and prompt. Include 2 photorealistic people/scenes. | AI_GENERATED | Detection of a current generator; C2PA presence |
| C03 | 5 | Gemini text-to-image | Download from Gemini. Record version and prompt. Same content mix as C02. | AI_GENERATED | Second current generator |
| C04 | 5 | AI image + manual Photoshop edit | Take an AI original (new or from C02/C03), edit with non-generative tools (crop, curves, clone stamp, text). Record every step. | AI_GENERATED (+MANUALLY_EDITED) | Does editing hide AI origin? |
| C05 | 5 | Real photo + manual Photoshop edit | From a phone original: remove an object with Clone Stamp/Healing, change colours, paste a region from another real photo. No generative tools. | MANUALLY_EDITED | Rule: Photoshop must not be called AI; editing detection |
| C06 | 5 | Real photo + generative AI edit | Generative Fill, inpainting in ChatGPT/Gemini/Firefly, object replacement. Record the tool and prompt. | AI_EDITED | Partial AI content inside a real photo |
| C07 | 5 | Messenger compression | Send 3 real + 2 AI originals through Telegram and WhatsApp **as photos** (not files), save the received image on the other device. Record app, version and direction. | inherited | Robustness to real messenger pipelines |
| C08 | 5 | Screenshots | Screenshot of real and AI images displayed on a phone/PC. Record device and how the image was displayed. | inherited | Loss of all metadata, rescaling |
| C09 | 5 | Format conversion / resize / recompress | Convert AI originals (PNG→JPEG, WEBP, resize 50%, JPEG q60) with any editor; record tool and settings. | inherited (AI_GENERATED) | Sensitivity to format and resolution |
| C10 | 5 | Mixed real + AI | Composite AI elements (person, object, background) into real photos in Photoshop or similar. Record which parts are AI. | MIXED | Composites, the most realistic misinformation case |

Optional advanced scenarios (register under these codes):

| Code | Scenario | Ground truth |
|---|---|---|
| A01 | AI upscaling (generative upscalers, Topaz, ChatGPT "increase resolution") | AI_EDITED (AI_GENERATED if parent is AI) |
| A02 | AI filters and retouching (face beautify, FaceApp, AI skin smoothing) | AI_EDITED |
| A03 | AI background removal / replacement | depends: removal only → MANUALLY_EDITED; generated new background → MIXED/AI_EDITED. Must be given explicitly. |
| A04 | Screenshot, then photograph of the screen with another phone | inherited |
| A05 | Several rounds of compression (scripted `multi_jpeg_5x`, or forwarding the same image 3× in a messenger) | inherited |
| A06 | Image-to-image AI transformation, including "improve the quality" in ChatGPT/Gemini | AI_EDITED |

**Independence.** Derivatives of one original are not independent samples. Aim for at least 30 independent sources:
use **new** phone photos (register them in `X00` with `--label REAL`) as the bases for C05–C08/C10, rather than
re-using the five C01 photos for everything. Every derivative stores `original_image_id` and `source_group_id`, and the
report gives a source-weighted accuracy.

## 4. Dataset rules

1. Originals are preserved. Put a **copy** of each file into its folder. `scan_test_dataset.py` never renames, moves or
   edits images; it records SHA-256, marks a file `changed` if it is later overwritten, and the evaluation refuses to run
   on a file that no longer matches its hash.
2. Every image gets a unique ID `DA-<category>-<nnn>`.
3. Every derived image links to its source via `original_image_id`; the tool refuses unknown links.
4. Tool, version, settings and prompts go in `origin_tool`, `transformation_tool`, `transformation_params`.
5. Ground truth lives in `manifest.csv`; predictions live in `results/run_*/predictions.csv`. They are never mixed.
6. This set is separate from `backend/eval_images`, which was used to choose the detector and thresholds. The runner
   refuses to run if any file is shared.
7. No thresholds or rules may be changed after viewing results of a run without re-running and reporting both runs.
8. Only photograph people who consent; record it in `consent_license`. Do not commit private photos publicly.

## 5. Folder structure

```
testing/
  TEST_PLAN.md          this document
  CHECKLIST.md          step-by-step execution checklist
  manifest.csv          one row per image (ground truth + provenance)
  originals/            untouched sources (C01, C02, C03, X00)
  derived/              every transformed image, one folder per category (C04–C10, A01–A06)
  results/run_<time>/   predictions.csv, confusion_matrix.csv, metrics.json, report.md
```

```
.venv\Scripts\python scripts\run_test_suite.py        # evaluate everything that has an image
```
