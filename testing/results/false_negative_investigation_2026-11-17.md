# Расследование ложноотрицательного результата (17.11.2026)

Регрессионный образ: `test_dataset/regression/known_ai_generated.jpg` (REG-001, GT = AI_GENERATED, 320×179, JPEG q≈85, WhatsApp, без EXIF/C2PA).
Исходный вердикт: `not_ai` (R4b), скан TL-2C8FE7A78767.

## 1. Корневая причина
1. Один детектор (SwinV2 `haywoodsloan/ai-image-detector-deploy`, AutoTrain, данные обучения не раскрыты). На этом изображении он **уверенно ошибается**: медиана 7 видов 0.0103, все виды 0.004–0.024, стабильность 1.0. Порог (0.80) ни при чём: снижение порога в 80 раз всё равно не поймало бы его.
2. Предобработка: 320×179 растягивается до 256×256 без сохранения пропорций; половинки (≈160 px) апскейлятся — изображение вне распределения обучения.
3. Пересжатие мессенджером и удалённые метаданные — у метаданных/C2PA не было шанса помочь.
4. Агрегация (R4b) выдавала «ИИ не обнаружен» по одному детектору на маленьком сжатом изображении — без учёта качества.
Сбоев загрузки/фоллбэка не было: модель работала на CUDA штатно.

## 2. Изменения пайплайна
* Второе независимое семейство детекторов: Community Forensics (frontier + low-quality, timm ViT-S/16-384, собственная предобработка автора: короткая сторона 440 → центр 384, ImageNet-нормализация, решение по сырому логиту против опубликованной границы).
* Родственные модели (lowq дообучена из frontier) = **один голос**, только при согласии.
* Правила: R2 (одно семейство «ИИ», ни одно «не ИИ»), R7 (семейства противоречат → «Не определено»), R9 (фильтр качества: длинная сторона < 512 px или JPEG ≤ 75 → «не ИИ» не утверждается), R1e/R2e (новый вердикт `ai_edited`).
* Оценки разных моделей не усредняются и не сравниваются на одной шкале; заголовочная «вероятность» убрана, вместо неё — уверенность детекции (согласие семейств), явно помеченная как «не вероятность».
* UI/PDF: таблица детекторов (решение, оценка, тип оценки, правило, вход), расхождение моделей, предупреждение о качестве; EN/RU/AZ.
* Веса CF закреплены по ревизии и SHA-256 (проверка при загрузке).
* Попутно найден и исправлен сбой отрисовки лиц у верхнего края кадра (падал весь анализ).

## 5. Регрессионное изображение
До: `not_ai` (R4b). После: `inconclusive` (R9) — SwinV2 «не ИИ» 0.010, CF frontier «не ИИ» 0.198, CF low-quality «ИИ» 0.710; семейство CF расходится → голоса нет; 320 px ниже порога качества. Во всех 4 вариантах — `inconclusive`. Вывести «ИИ» можно было бы, только доверившись одной lowq-модели, которая ложно обвиняет 3/35 реальных фото, — это было бы подгонкой под одну картинку.

## 6. Ограничения
* Данных мало: 19 ИИ / 35 не-ИИ оригиналов + производные варианты, а не 100/100; скриншотов нет; eval_set смещён (по нему выбирали SwinV2).
* Цена: заметно больше «Не определено» (на JPEG q70 все реальные фото становятся «Не определено»), появился 1 ложный «ИИ» на реальном селфи из WhatsApp (B-11).
* Калибровка CF — авторская, на наших данных не проверена.
* Фотошоп-правки (edit_set 0/10) и ИИ-правки по-прежнему почти не обнаруживаются пиксельно; `ai_edited` срабатывает в основном по метаданным.
* Ни один детектор не находит все ИИ-изображения.
