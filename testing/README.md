# Detective AI test dataset — how to add images

The dataset starts as **50 planned, empty test cases** (`manifest.csv`, `slot_status = planned`).
You fill them by copying images into folders. Nothing here is generated or downloaded automatically.

## 1. Put a copy of each image in its folder

| Folder | Put here | Ground truth (automatic) |
|---|---|---|
| `originals/C01_real_smartphone/` | Phone photos copied **as files** (cable/cloud), not via a messenger | REAL |
| `originals/C02_ai_chatgpt/` | Images generated by ChatGPT (original download) | AI_GENERATED |
| `originals/C03_ai_gemini/` | Images generated by Gemini (original download) | AI_GENERATED |
| `derived/C04_ai_plus_photoshop/` | AI images edited by hand in Photoshop (no generative tools) | AI_GENERATED (+MANUALLY_EDITED) |
| `derived/C05_real_plus_photoshop/` | Real photos edited by hand in Photoshop (clone, heal, colour, paste a real photo) | MANUALLY_EDITED |
| `derived/C06_real_plus_genai_edit/` | Real photos changed with Generative Fill / inpainting / AI object replacement | AI_EDITED |
| `derived/C07_messenger/` | Images sent **as photos** via Telegram/WhatsApp and saved on the receiving phone | same as its original |
| `derived/C08_screenshot/` | Screenshots of real or AI images | same as its original |
| `derived/C09_format_resize_recompress/` | AI images converted (PNG→JPEG/WEBP), resized or re-compressed | same as its original |
| `derived/C10_mixed/` | Composites with real and AI parts | MIXED |
| `derived/A01…A06_*/` | Optional advanced cases (upscaling, AI filters, background, screen re-photo, multi-compression, image-to-image incl. "improve this photo" in ChatGPT) | see TEST_PLAN.md |

Supported formats: JPG, PNG, WEBP. Keep your own original file somewhere else too; never overwrite a file that
is already in the dataset.

**Which slot does a file go to?**
- Name the file with its slot ID to choose it, e.g. `DA-C05-002_removed_car.jpg` (the plan for each slot is in the
  `planned_case` column of `manifest.csv`).
- Without an ID in the name, the file takes the first empty slot of that folder's category.

## 2. Scan

Run from the `backend` folder:

```
.venv\Scripts\python scripts\scan_test_dataset.py
```

The scanner fills `file_path`, `sha256`, `file_size`, `width`, `height`, `format`, `slot_status = present`, and
prints `present/planned` per category. It never renames, moves or edits your images. If a registered file is
later changed or deleted it is marked `changed` / `missing` and left out of the evaluation.

## 3. Fill in what only you know (in `manifest.csv`, e.g. with Excel)

For each image you added:
- `origin_tool`: ChatGPT / Gemini / phone model …
- `transformation_tool` and `transformation_params`: exact tool and settings, e.g.
  `Adobe Photoshop 2025 — Clone Stamp` / `removed the car on the left`, or `WhatsApp 2.25 Android` / `sent as photo`.
- `original_image_id`: for derived images, the ID of the image it was made from. The plan pre-fills a suggestion
  (e.g. C05-001 is made from C01-001); **change it if you used a different source**.
- `ground_truth`: pre-filled from the category. Change it only if the case is different from the plan
  (e.g. an A03 background replacement). `TBD` rows are not evaluated until you set a label.
- `consent_license`: e.g. "own photo", "person agreed".

Run the scanner again after editing: it recomputes source groups and inherited labels without touching your text.

## 4. Evaluate

```
.venv\Scripts\python scripts\run_test_suite.py
```

Only cases with an image (`present`) and a valid label are evaluated; empty slots are listed as coverage.
Results go to `results/run_<date>_<time>/`:
- `predictions.csv` — per image: ground truth, predicted verdict, detector score and view agreement, metadata findings,
  processing time, correct / incorrect / inconclusive
- `confusion_matrix.csv`
- `metrics.json` and `report.md` — precision, recall, F1 (with 95% intervals), false positives / false negatives,
  breakdown by category, source tool and transformation, coverage of the 50-case plan

All numbers come from the actual run. Ground truth is never changed by the scripts.

## Labels (short version — details in TEST_PLAN.md)

`REAL` · `AI_GENERATED` · `AI_EDITED` (real photo changed by generative AI) · `MANUALLY_EDITED` (Photoshop without
generative tools) · `MIXED` (real + AI parts) · `INCONCLUSIVE` (origin unknown, not evaluated).
Ordinary Photoshop editing is never AI generation.
